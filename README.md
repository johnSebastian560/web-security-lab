# Web Security Lab

A practical collection of web application security testing exercises performed in controlled laboratory environments.

## Objectives

- Understand web application attack surfaces
- Practice reconnaissance and enumeration
- Identify common OWASP vulnerabilities
- Test authentication and authorization controls
- Analyze HTTP requests and responses
- Document security findings
- Understand remediation techniques

## Areas Covered

### Reconnaissance
- Nmap
- HTTP enumeration
- Technology identification
- Directory and endpoint discovery

### Web Security
- SQL Injection
- Cross-Site Scripting (XSS)
- IDOR
- CSRF
- File Upload vulnerabilities
- Authentication issues
- Access-control weaknesses

### API Security
- Authentication testing
- Authorization testing
- BOLA/IDOR
- Parameter manipulation
- API endpoint enumeration

### Tools

- Nmap
- Burp Suite
- FFUF
- Gobuster
- HTTPX
- Wireshark
